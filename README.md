# Mohammed Aisha - Professional Pen Tester Portfolio

A modern, responsive portfolio website showcasing cybersecurity expertise, penetration testing skills, and professional achievements.

## Features

- **Cybersecurity Theme**: Dark, terminal-inspired design with matrix background effects
- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Interactive Elements**: Smooth scrolling, animations, and hover effects
- **Complete Sections**:
  - Hero section with glitch text effects
  - About Me with professional background
  - Skills & Expertise (Penetration Testing, Tools, Programming, Methodologies)
  - Projects & Portfolio showcasing security assessments
  - Certifications & Training credentials
  - Contact section with social links

## Technologies Used

- HTML5
- CSS3 (with custom animations and effects)
- JavaScript (vanilla)
- Font Awesome icons

## How to View

Simply open `index.html` in your web browser or host it on any web server.

### Local Development

```bash
# Using Python
python3 -m http.server 8080

# Using Node.js
npx http-server -p 8080
```

Then navigate to `http://localhost:8080` in your browser.

## Customization

To personalize this portfolio:

1. Update personal information in `index.html`:
   - Name in the hero section
   - About section content
   - Skills and certifications
   - Project descriptions
   - Contact information

2. Modify colors in `styles.css`:
   - Primary color (green): `--primary-color`
   - Secondary color (cyan): `--secondary-color`
   - Background colors: `--background-dark`, `--background-darker`

3. Adjust animations and effects in `script.js`
